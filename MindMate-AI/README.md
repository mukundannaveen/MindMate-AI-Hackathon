# MindMate AI — Student Well-Being Hackathon MVP

A polished React + Vite prototype for the theme **AI for Student Well-Being**.

## Run
```bash
npm install
npm run dev
```
Then open the local Vite URL shown in the terminal.

## MVP flow
1. Student opens dashboard.
2. Completes a 60-second mood/stress/sleep/study check-in.
3. Local wellness engine calculates a non-medical well-being score.
4. The dashboard updates with personalized tips.
5. Smart study plan encourages focused work + recovery breaks.
6. Support section directs students toward trusted/campus/professional help when needed.

## Responsible AI
This MVP intentionally does not diagnose mental-health conditions. It is a self-awareness and routine-support tool. For the hackathon presentation, disclose AI assistance used during ideation/coding/design and explain the scoring logic honestly.
